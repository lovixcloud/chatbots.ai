# REST API Reference

* `POST /api/auth/register` — Register user & workspace.
* `POST /api/auth/login` — Authenticate and receive JWT token.
* `GET  /api/bots` — List workspace chatbots.
* `POST /api/bots/:id/playground` — Test bot responses with debug inspector.
* `GET  /api/faqs` — Search and filter knowledge base FAQs.
* `POST /api/widget/chat` — Public endpoint processing customer widget messages.
* `GET  /api/analytics/overview` — Calculated workspace performance metrics.
